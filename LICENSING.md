## Open-source core

The app and UI are licensed under [AGPL-3.0-only](LICENSE). The app includes pastes, collections,
revisions, secrets, the API, remote MCP, and OAuth, which you can run on your own instance.

The TypeScript SDK (`packages/sdk`), Python SDK (`packages/sdk-python`), CLI (`packages/cli`),
MCP package (`packages/mcp`), shared schemas (`packages/contracts`), and Raycast extension
(`plugins/raycast`) are licensed under MIT. The CLI bundles Zod through the shared schemas and
includes its license notice.

Existing published package versions are unchanged. New releases built from this source use
the package licenses described above.

Sniptide Cloud runs the same open-source core. The licenses above cover the code in this
repository. See the [Cloud terms](https://sniptide.com/terms) for use of the hosted service.
