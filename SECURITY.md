# Security policy

## Report a vulnerability

Report security issues privately through
[GitHub's private vulnerability reporting](https://github.com/Dino-Kupinic/sniptide/security/advisories/new).
Keep vulnerability details in the private report. Use a redacted example and leave out
credentials and other people's data.

Include the affected version or URL, the steps to reproduce, and the impact you observed.
Maintainers use the private report to coordinate investigation and disclosure. If you prefer
to stay anonymous in any published advisory, say so in the report.

## Supported versions

[Upgrade](https://docs.sniptide.com/self-hosting/upgrading) self-hosted instances to the latest
release to receive available security fixes.

## Scope

This policy covers the web app, API, MCP server, CLI, SDKs and self-hosting code in this repository.
Limit testing to data and accounts you control. Run automated scans on your own instance.

The [security and threat model](https://docs.sniptide.com/security) describes which data the
server operator can read and what users can expect from access controls and encryption.
