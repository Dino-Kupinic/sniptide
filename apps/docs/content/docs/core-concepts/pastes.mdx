title: Pastes
description: Look up what a Sniptide paste can hold, how its link works, how drafts and saving behave, and what the trash keeps.

A paste is what you share in Sniptide: a title, an optional description and 1 to 10 files, reached
through a link of its own.

## What a paste holds

| Part | Rule |
| --- | --- |
| Title | Required, up to 120 characters. The editor suggests one from the first file. |
| Description | Optional, up to 280 characters. |
| Files | 1 to 10. Each needs a name that is unique within the paste, up to 120 characters. |
| Size | 1 MB for all files together by default. The administrator sets it with `MAX_PASTE_SIZE`. |
| Language | Set from the file name, or detected from the code when the file still has a generated name. Choose **Change language** on a file to set it yourself. |

At least one file must contain code before the paste can be saved.

| Account limit | Default | Set by |
| --- | --- | --- |
| Pastes | 1,000, trash included | `ACCOUNT_PASTE_LIMIT` |
| Storage | 100 MiB of paste content, trash included | `ACCOUNT_STORAGE_BYTES` |
| New pastes | 30 an hour | Fixed |
| Manual edits | 240 an hour | Fixed |
| Auto-saves | 1,800 an hour | Fixed |

**Settings** > **Usage** shows how much of the paste and storage limits you use.

## The link

Every paste has a link, `<domain>/<link>`. By default the link is eight random characters from a
57-character alphabet, giving about 111 trillion possible generated links. Existing links keep
their address when you upgrade.

Set **Custom link** to choose your own: 3 to 40 letters, digits, hyphens or underscores. A link
another paste already has is refused.

When you change a paste's link, the old link stops working at once. The paste keeps its history,
collection and view counts, because those belong to the paste rather than to the link.

Each file is also available as plain text at `<domain>/<link>/raw?file=<file name>`. See
[Raw access](/core-concepts/sharing#raw-access).

## Create and edit a paste

1. Select **New paste**, or press <Kbd>N</Kbd>, to open the editor.
2. Type or paste code. Until you create the paste, the editor keeps your work as a draft on this
   device. Press <Kbd>Ctrl+S</Kbd> (<Kbd>⌘S</Kbd>) to save the draft, and opening the editor again offers to restore
   it.
3. Press <Kbd>Ctrl+Enter</Kbd> (<Kbd>⌘ Enter</Kbd>) to create the paste.

An existing paste saves as you type, and the header shows when it was last saved. Select **Done**
to end the editing session. The next edit then starts a new [revision](/core-concepts/revisions).

When the code looks like a secret, such as an API key or `.env` lines, the editor warns you and
switches a new paste to **Private**, because anyone with the link can read an unlisted or public
paste. Turn the warning off with **Secret detection** under **Settings** > **General**.

Pastes you create in the web editor start with the visibility, expiry and burn setting from
[your paste defaults](/settings#set-paste-defaults), which are **Unlisted**, **1 week** and off
until you change them.

## Find and act on pastes

- **Star** a paste to list it under **Starred**.
- Press <Kbd>⌘K</Kbd> (<Kbd>Ctrl+K</Kbd>) to search your pastes by title or link and your collections by name.
- **Duplicate** copies a paste into a new one that you own.
- In the **Pastes** list, select rows with their checkboxes to star, move, change the visibility
  of or trash several pastes at once. Shift-click selects a range, and `Esc` clears the selection.
  Actions that can be taken back end with an **Undo** button.

## Trash

**Move to trash** removes the paste from every list and stops its link at once. You can
**Restore** it from **Trash** for 30 days. After that it is deleted for good. **Delete forever**
and **Empty trash** remove pastes right away and ask you to confirm first.
[Burned](/core-concepts/burn-after-read) pastes also land in the trash, marked with when they
were read, and come back private when you restore them. A paste that expired keeps its full 30
days once you move it to the trash.

A paste in the trash still counts toward your paste and storage limits until it is deleted.
