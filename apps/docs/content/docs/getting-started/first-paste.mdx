title: Make your first paste

---

This guide takes you from a new account to a paste that is filed in a collection and shared
through a link. It takes about five minutes.

<FirstPasteVisual />

## Before you begin

- Open the hosted app at `app.sniptide.com`, or your own instance's address if you
  [run Sniptide yourself](/getting-started/self-hosted). The steps are the same on both.
- Have an email address, or a GitHub or Google account if the instance offers those sign-ins.

<Steps>
<Step>

### Create an account

Open the app and select **Create account**. Choose a username of 3 to 30 lowercase letters,
digits, hyphens or underscores, enter your email and set a password of at least 8 characters.
GitHub and Google sign-in appear when the instance has them turned on.

An instance can limit sign-up. On an invite-only instance only the email addresses the
administrator allowed can join, and a closed instance has no sign-up form. The sign-up page tells
you which applies.

After sign-up the app opens a short welcome setup. It asks how you found Sniptide and what you'll
use it for, then offers to [connect a coding agent](/mcp). Select **Skip setup** to go straight to
the dashboard.

</Step>
<Step>

### Create a paste

Select **New paste** in the sidebar, or press `N` anywhere in the app. Type or paste your code.
Sniptide suggests a title and a file name from the code, and you can change both. A paste holds
up to 10 files. Select **Add file** for another one.

The settings beside the editor decide who can open the paste and for how long. A new paste starts
as **Unlisted** and expires after **1 week** until you change your defaults in **Settings**. If
the code looks like it contains a secret, such as an API key or `.env` lines, the editor switches
the paste to **Private** and shows a warning. [Sharing](/core-concepts/sharing) explains every
option.

Press `Ctrl+Enter` (`⌘ Enter` on a Mac) to create the paste.

The paste opens on its own page, and its link appears in the address bar as
`<domain>/<link>`, for example `app.sniptide.com/k3j9xq2m`. The eight random characters differ for
every paste.

</Step>
<Step>

### File it in a collection

A collection groups your pastes in the sidebar. Select **New collection** in the sidebar, enter a
name and create it. Then open the paste's menu in the sidebar and select **Add to collection**,
or pick the collection in the paste's **Collection** setting while you edit it.

The collection appears in the sidebar with the paste under it. See
[Collections](/core-concepts/collections).

</Step>
<Step>

### Share the link

Select **Copy link** on the paste. Anyone can open the link while the paste is **Unlisted** or
**Public**.

To share with specific people instead, set the paste to **Private**, select **Share** and invite
them by email or username. They find the paste under **Shared with me**, with view or edit
access, and everyone else gets a "not found" page.

A collection stays private to you, so you share the pastes in it, one at a time.

</Step>
</Steps>

## Check the result

Open the copied link in a private browser window. You see the paste's code without signing in.
If you made the paste private, you see a "not found" page instead, which is the expected result.

## Clean up

To remove the test paste, open its **More actions** menu and select **Move to trash**. The link
stops working at once, and you can restore the paste from **Trash** for 30 days.
