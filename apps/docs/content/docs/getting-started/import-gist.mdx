---
title: Import a GitHub gist
description: Copy the files of a public GitHub gist into a new Sniptide paste, with your default visibility and expiry.
---

Import a public gist when your snippets already live on GitHub. Sniptide copies the files you
choose into a new paste, so later changes to the gist don't reach it.

## Before you begin

- The gist must be public. Sniptide can't read secret gists.
- The usual paste limits apply: at most 10 files, 120 characters per file name and 1 MB per paste
  by default.

## Import the gist

<Steps>
<Step>

Select **Import gist** in the sidebar.

</Step>
<Step>

Paste the gist's link, such as `gist.github.com/you/1a2b3c…`, or only its id. Sniptide reads the
gist and lists its files with their sizes. Nothing is saved yet.

</Step>
<Step>

Choose the files to import, at least one and at most 10. A file that can't be imported shows the
reason, for example that it is over the size limit.

</Step>
<Step>

Select **Import now**.

</Step>
</Steps>

## Check the result

The new paste opens. Its title is the gist's description, or the first file's name when the gist
has none, and its description reads "Imported from gist" followed by the gist's id. The paste
uses the visibility and expiry from your [paste defaults](/settings#set-paste-defaults). When a
chosen file looks like it contains a secret, such as `.env` lines or an API key, the paste is
created as **Private** instead. The import screen shows both settings before you import.

Edit the paste to change its title, visibility, expiry or collection like any other paste.

## Limits

| Limit | Value |
| --- | --- |
| Gist reads | 20 an hour per account |
| New pastes | An import counts toward the 30 new pastes an hour per account |
| GitHub quota on a self-hosted instance | 60 requests an hour for the whole server, unless the administrator sets `GITHUB_TOKEN` |

When a gist doesn't exist or isn't public, Sniptide says so and saves nothing. An administrator
can raise the GitHub quota by setting `GITHUB_TOKEN` to a token with no scopes. See
[Configuration](/self-hosting/configuration#pastes-and-sharing).
