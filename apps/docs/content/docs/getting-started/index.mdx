There are two ways to use Sniptide: the hosted app, or an instance you run yourself. The app is the
same either way.

<Cards>
  <Card title="Hosted: your first paste" href="/getting-started/first-paste" description="Sign up, make a paste, file it in a collection and share it." />
  <Card title="Import a GitHub gist" href="/getting-started/import-gist" description="Bring an existing public gist in as a paste." />
  <Card title="Self-hosted: run your own" href="/getting-started/self-hosted" description="Docker Compose, a secret and an account, in a few minutes." />
</Cards>

New to Sniptide? Start with the hosted walkthrough. It ends with a shared paste, and the
[core concepts](/core-concepts) explain each setting you meet along the way.
