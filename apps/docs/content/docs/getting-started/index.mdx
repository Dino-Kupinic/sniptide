Each guide below ends with a result you can check: a shared paste, an imported gist or a running
instance. The app works the same on sniptide.com and on your own server.

<Cards>
  <Card title="Make your first paste" href="/getting-started/first-paste" description="Create an account, save a paste, file it in a collection and share the link." />
  <Card title="Import a GitHub gist" href="/getting-started/import-gist" description="Copy the files of a public gist into a new paste." />
  <Card title="Run your own Sniptide" href="/getting-started/self-hosted" description="Start the app and Postgres with Docker Compose and create your account." />
</Cards>

If you are new to Sniptide, start with [Make your first paste](/getting-started/first-paste) on the
hosted app. [Core concepts](/core-concepts) explains each setting you meet along the way.
