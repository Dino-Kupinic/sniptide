Sniptide saves code as pastes, shares each one with a link whose visibility, password and expiry
you choose, and lets the CLI, the SDKs and coding agents read and save the same pastes. The hosted
app runs at `app.sniptide.com`, and you can run the same app on your own server with Docker.

## Choose how you work with Sniptide

| You want to | Use | Authenticates with |
| --- | --- | --- |
| Write, organize and share pastes by hand | The web app | Your account |
| Let a coding agent search, read and save snippets | The [MCP server](/mcp) | [OAuth](/oauth) or an [API token](/api-tokens) |
| Capture files from a project and restore them elsewhere | The [CLI](/cli) | An API token |
| Call Sniptide from your own code | The [SDKs](/sdks) or the [token API](/api-tokens) | An API token |

Every route reaches the same pastes, collections and env groups. A token or an agent connection
only reaches the pastes of the account that created it.
