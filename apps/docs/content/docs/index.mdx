Save a snippet, a config file or several related files in a paste. Share it for a quick review,
or keep it in a collection so you and your coding agents can find it again. You choose who can
open the link and when it expires.

## Start here

Open [Sniptide Cloud](https://app.sniptide.com) or follow the self-hosting guide to set up
an instance on your server.

## Share and reuse your work

- [Share a paste for review](/core-concepts/sharing). Invite specific people to view or edit it,
  or send an expiring link.
- [Organize snippets you reuse](/core-concepts/collections). Group related pastes and retrieve
  them together from the CLI or an agent.
- [Sync a project's environment variables](/cli#sync-env-files). Pull an encrypted env group
  into a local project or run a command with its values.

## Choose how you work with Sniptide

| You want to | Use | Authenticates with |
| --- | --- | --- |
| Write, organize and share pastes by hand | The web app | Your account |
| Let a coding agent search, read and save snippets | The [MCP server](/mcp) | [OAuth](/oauth) or an [API token](/api-tokens) |
| Capture files from a project and restore them elsewhere | The [CLI](/cli) | An API token |
| Call Sniptide from your own code | The [SDKs](/sdks) or the [token API](/api-tokens) | An API token |

Every route reaches the same pastes, collections and env groups. A token or an agent connection
only reaches the pastes of the account that created it.
